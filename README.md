# 睛彩乐园 · Vision Garden

一个无需构建、无需安装依赖的中文视觉互动网页项目，使用原生 HTML、CSS、JavaScript 和 SVG。

## 功能

- 动物填色：狐狸、小猫、兔子，6×6 共 36 色调色盘，按参考图匹配部位颜色。
- 填错惩罚：填错 1 次闪红提示，累计填错 2 次整幅清空、从头再来。
- 寻点描画：8 个角色（小汽车、小火箭、小帆船、小房子、热气球、狐狸、小猫、兔子），绿点按顺序落在图案主线条上，点一个长一段；描完 16 个点后浮现真实配色的整幅图案。
- 打地鼠：九个等大的洞，地鼠每 1.5 秒换洞。
- 瓶子倒墨水：每瓶容量 7 滴，选择两个瓶子倒入同色墨水，带倾斜动画。
- 彩色挪车：每关 45～50 辆密集排列的小型斜向车辆，相邻车辆方向不同，沿车头方向向四个斜向出口驶离；出口判定按真实车身尺寸做连续碰撞检测，画面看着被挡的车一定开不出去，且每关数学上保证可清场。
- 快上车：上方彩色乘客持续排队，5 个停靠位，下方停车场点击派车。车辆有不同座位数，只接队首同色乘客，坐满才驶离；一轮完成后自动补充下一批车辆与乘客。支持撤销派车。
- 黑白块、红绿块、黑白条纹及混合交替背景，按弱视训练标准组合随机轮番显示，每 5 秒自动切换，标准闪速每秒 2 次，无需手动调节。
- 暂停、撤销、重新开始、全屏和计时。
- 六个游戏均有点击音效（WebAudio 实时合成，含统一主音量放大），设置中可统一开关，开关状态会保存在当前浏览器。
- 支持电脑和平板布局；无服务端、无账号、无分析追踪。

## 运行

直接在浏览器中打开 `index.html`，或在项目目录运行：

```bash
python -m http.server 8080
```

然后访问 http://localhost:8080 。项目也可部署到任意静态网站托管服务。

## 文件

每个小游戏都是独立页面，有自己的目录和专属音效；公共样式、音效引擎与游戏外壳在 `shared/`。

```text
index.html              游戏大厅，链接到六个游戏页
shared/base.css         基础布局、调色盘与闪烁背景样式
shared/games.css        打地鼠 / 倒墨水 / 挪车等游戏布局
shared/bus.css          快上车公交站布局
shared/audio.js         音效引擎（WebAudio 合成，含各游戏专属音色与静音开关）
shared/shell.js         游戏外壳：工具栏、暂停/重玩、训练背景自动轮播、通用面板
shared/animals.js       填色与寻点共用的 SVG 素材（3 个动物 + 5 个图案角色）
games/color/            动物填色（正确 / 出错 / 清空音效）
games/dots/             寻点描画（绿点"啵"声 / 完成胜利音）
games/mole/             打地鼠（命中上扬音 / 落空轻点 / 结束胜利音）
games/water/            瓶子倒墨水（选瓶 / 倒水滑音 / 倒错提示 / 归位胜利音）
games/cars/             彩色挪车（出发引擎声 / 被挡提示 / 清场胜利音）
games/bus/              快上车（派车进站 / 按颜色变调的上车音阶 / 满座出发 / 整波完成）
```

音效全部由 WebAudio 实时合成，没有外部音频文件；开关状态保存在当前浏览器，六个游戏页共享同一个开关。

拆分前的单页版本（`app.js`、`games.js`、`traffic.js`、`bus.js` 等）不再随仓库分发，需要时可在 git 历史中找到。

## 使用说明与限制

这是互动演示项目，不是经过临床验证的医疗器械或治疗方案，不用于诊断、评估疗效，也不声称促进眼轴发育或改变屈光状态。弱视相关诊疗应由眼科医生指导。

背景按弱视训练常见组合自动轮播：红绿块、黑白块、黑白条纹、黑白红绿交替，每 5 秒随机切换一次且不连续重复，画面切换频率为每秒两次，无需手动调节；暂停或切到后台时停止轮播。这些是动画参数，不代表医学建议或安全保证。闪烁可能引起光敏不适，有光敏性癫痫史者请勿使用闪烁模式；出现不适时立即停止，可按暂停按钮停止动画。

进度保存在当前页面内存中，刷新会重置。现有验证覆盖脚本语法、核心玩法、关卡可解性和桌面浏览器预览；仍建议按实际使用设备检查显示效果。

## 开发

无需编译。修改项目文件后刷新即可。动物和车辆由代码内 SVG 路径绘制，没有外部图片或字体依赖。
